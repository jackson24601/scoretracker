# Classroom Scoreboard

A simple browser scoreboard for classroom activities.

## How to use

Open `index.html` in a browser. No install or server is required.

- Choose **1–4 teams** at the top.
- Click **+** or **−** next to a team to keep a running score.
- Click a team name to rename it.
- Use **Reset scores** to set every team back to 0.
- Use **Full screen** when projecting the board to the class.

Scores and team names are saved in the browser, so a refresh will not wipe the current game.
